# Hoja de ruta

La versión 0.2 amplía el prototipo a un editor de composiciones y un modelo ideal
de placas/cámaras. La siguiente prioridad científica es determinar dónde ese
modelo describe ensayos reales. Los hitos siguientes no prometen fechas ni
precisión sin datos suficientes.

| Área | Entrega v2 | Siguiente criterio de aceptación |
| --- | --- | --- |
| Motor | Flexión y pérdidas, una a tres hojas, cámaras de aire, relleno Miki, integración energética por banda | Revisar derivación con fuentes primarias y contrastar curvas experimentales reservadas |
| Experiencia de uso | Composición por hojas/capas/cámaras, sección, biblioteca y resultados de espacio ajustable | Pruebas de tareas con consultores y ejecución nativa en Windows |
| Catálogo internacional | Importador local de seis familias suministradas y procedencia conservada | Verificar fichas y propiedades, resolver unidades pendientes, ampliar datos públicos redistribuibles |
| Clasificación | Rw provisional contrastado algorítmicamente | Revisión primaria de ISO 717-1 y casos normativos; incorporar C/Ctr solo después |
| Reproducción | Proyectos versionados, ejemplos sintéticos, CLI e informes | Publicar expedientes completos de validación y límites de uso |
| Distribución | Fuentes y paquete Python | Instalador Windows probado, avisos/licencias y actualización revisados |

## Pendientes científicos prioritarios

1. Verificar las ecuaciones, las hipótesis de unión entre capas y el tratamiento de
   bandas con bibliografía primaria, sin confundir contraste de código con ensayo.
2. Incorporar mediciones independientes de placas simples y dobles hojas realmente
   desacopladas, con geometría, montaje, propiedades e incertidumbre documentados.
3. Definir tolerancias y dominio de aplicación antes de ajustar parámetros. Separar
   datos de calibración y evaluación, incluyendo los casos que no se reproduzcan.
4. Modelar transmisión estructural por montantes y fijaciones con evidencia
   específica. Añadir una lista de bastidores no resuelve este problema físico.
5. Evaluar tamaño finito, bordes, cizalladura en placas gruesas, ortotropía,
   acristalamientos laminados y marcos según sus dominios correspondientes.

Los modos propios de ventanas pequeñas, las rendijas/agujeros con difracción,
los revestimientos de suelo, los núcleos acoplados y los perfiles necesitan
modelos completos y verificaciones propias. V2 solo representa una fuga como
área abierta ideal de transmisión unitaria. La presencia de otros datos en la
biblioteca no implica disponibilidad de una predicción.

## Ampliaciones de alcance

STC, C/Ctr, IIC, Ln,w, L'nT,w, ruido de lluvia y el aislamiento entre recintos
ISO 12354 requieren rutas de cálculo y normas específicas. Se mantendrá visible
qué magnitud produce cada cálculo. No se deducirá un índice de impacto a partir
de una curva de aislamiento aéreo.

La guía INSUL 10, sus capturas y el folleto ya fueron revisados como referencias
funcionales; [el registro v2](v2-reference-review.md) documenta las secciones y
bibliografía identificadas. La reproducción de controles o una similitud entre
índices globales no demuestran equivalencia entre motores.
