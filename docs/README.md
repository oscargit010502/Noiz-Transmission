# Documentación técnica

Noiz Transmission 0.2 permite editar composiciones de una a tres hojas, importar
bibliotecas locales y calcular transmisión aérea ideal de placas y cámaras, con
flexión, pérdidas y relleno poroso opcional. La precisión experimental de sistemas
comerciales sigue pendiente de evaluación.
